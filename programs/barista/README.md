# 로봇 바리스타 컨트롤러 (1단계, 2026-10-02)

휴게소 로봇 카페처럼 **주문 → 컵 → 에스프레소 → (우유) → 픽업대**를 해내는 프로그램. 실행 중에 AI(Claude)를 쓰지 않는다 — 정해진 순서(상태 기계)와 센서 확인, 복구 절차로 움직인다. Claude는 개발을 같이 한 도구일 뿐이다.

```bash
..\..\.venv\Scripts\python programs\barista\run.py                        # 주문 3개 + 영상 sim/out/barista.mp4 (3배속)
..\..\.venv\Scripts\python programs\barista\run.py --view                 # 실시간 3D 창
..\..\.venv\Scripts\python programs\barista\run.py --trials 10 --mess 8   # 컵을 최대 8mm 어긋나게 10번 → 성공률
```

## 만들면서 부딪힌 것 (실물에서도 똑같이 생김)
1. **집게 속에서 컵이 쏠린다(2~9mm, 잡을 때마다 다름)** → 놓은 자리가 조금씩 틀어짐. 「놓은 위치 기억」으로는 못 다시 집음 → **집기 전에 항상 카메라로 확인**
2. **노즐·스테인리스 받침이 카메라에 흰색으로 보임** → 받침을 어두운 색으로, 노즐은 컵 뒤쪽에서 비스듬히(위에서 컵 전체가 보이게). 현장에서도 비전 영역 배경은 어둡게 둔다
3. **보는 자세의 접힌 팔이 에스프레소 자리를 가림** → 받침을 옆(빈 쪽, 1.9rad)으로 돌려 접음
4. **접힌 자세에서 바로 뻗으면 팔이 낮게 휘두름** → 접고 펼 때 항상 준비 자세로 세웠다가
5. **한쪽 턱이 경첩으로 벌어지는 집게** — 열린 상태 두 턱 가운데는 4cm 넘게 벗어남 → 역기구학은 닫힌 모양으로 풀고 연 채로 이동(`move_open_to`)
6. **끝까지 벌리면(9.5cm) 옆 칸 컵을 쳐서 끌고 감** → 컵에 맞춰 0.35rad(약 4.4cm)만 벌림
8. **실패 4건 분석(2026-10-02)**: 「컵 보관대가 비었음」 3건은 잡기 실패가 아니었다 — 옆 컵 쪽으로 9mm 어긋난 컵을 집으려고 내려갈 때 벌린 턱이 옆 컵을 쳐서 넘어뜨렸고, 넘어진 컵이 천천히 굴러감. 보관대 칸 간격 58mm → 약 80mm, 벌림 5cm → 4.4cm로 고쳐 30/30. 현장 교훈: **컵 보관대(지그) 간격은 집게가 벌어지는 폭 + 놓임 오차를 견디게 설계**
7. 카메라 창 안에 접힌 팔 끝이 같이 잡힘 → 자리 중심에 가장 가까운 흰 덩어리만 사용

## 2단계: 머신이 도는 동안 다음 일 (2026-10-02)
`run.py --mode pipe` — 이벤트 기반 스케줄러(`Barista.run_pipelined`). 매번 「지금 할 수 있는 일」 중 가장 앞선 주문의 일을 고르고, 없을 때만 가장 먼저 끝나는 머신을 기다린다.

| 조건(에스프레소 20초·우유 12초, 아메리카노·라떼·아메리카노) | 3잔 전체 | 차이 |
|---|---|---|
| `seq` 한 잔씩 끝까지 | 144.6초 | — |
| `pipe` 머신이 도는 동안 다음 일 | **124.2초** | **-20.4초(-14%)** |

읽는 법: 로봇 한 번 옮기기(보기→집기→놓기)가 약 8~10초, 에스프레소가 20초라 **병목은 에스프레소 머신 한 대**다. 라떼의 우유 단계와 다음 잔 추출이 겹친 만큼만 줄었다. 더 줄이려면 ① 머신 옆 「다음 컵 대기 자리」 ② 에스프레소 2대 — 실제 공장의 병목 공정 분석과 같은 결론(교육 소재).
